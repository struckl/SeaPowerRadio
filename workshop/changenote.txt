1.3.0: names for mod ships.
Ships from other mods that carry a hull prefix (USS, HMS, HMCS, FGS, ...) now say their name without it, so a modded "USS Pargo" says "Pargo" instead of a generated callsign.
New file BepInEx/config/SeaPowerRadio/aliases.txt (created at your first mission, updates never touch it): map any ship onto a name the mod has clips for, and optionally pin it to one voice, e.g. "HMS Bristol = Bristol | gb_m_06". Ship mods can ship their own rats-radio-aliases.txt. Details in the README on GitHub.
It can only use names that already have clips (every ship and shore unit of the base game); a completely new name still gets a callsign.
